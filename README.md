# Noor Haddad - Academic Homepage

Academic homepage for Noor Haddad, first-year PhD candidate at Delta Language Analytics (part of Delta Science University), built from the [Academic Pages template](https://github.com/academicpages/academicpages.github.io).

All personal details, academic background, research experience, skills, publications and contact information on this site come from the memory record (`memory/memory.json`); nothing has been added beyond it.

## Where the content lives

* `_config.yaml` - site configuration and author/contact details. This site intentionally uses `_config.yaml` instead of the template's default `_config.yml`.
* `_pages/about.md` - the about section: biography, education, research experience, skills, honors, the full list of publications, and contact details.
* `_pages/cv.md` - CV page: education, research experience, doctoral research, skills, honors and awards, publications, contact.
* `_publications/` - one record per publication.
* `_data/navigation.yml` - header menu (Publications, CV).
